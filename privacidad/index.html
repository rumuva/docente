Privacidad de esta versión

Información sobre el funcionamiento de la web.

Navegación

Esta versión es una web estática. No incorpora analítica, cookies publicitarias, formularios de suscripción ni cuentas de usuario. Las fotos, el logotipo y las ilustraciones están incluidos en el propio archivo.

Contacto

El formulario permite abrir un borrador en la aplicación de correo, copiar su contenido o descargar un archivo de texto (.txt). El texto se conserva únicamente en la memoria de esta página mientras siga abierta, sin guardarse en el dispositivo. Se pierde al recargarla o cerrarla. La web no envía los campos a un servidor.

Cuando envíes un correo desde tu aplicación, se utilizará tu proveedor de correo habitual. Para consultas, escribe a rumuva1492@gmail.com.

Sobre esta web

Esta web presenta el perfil profesional, las acreditaciones y los materiales didácticos de Rubén Muñoz Valadés. Para cualquier consulta, utiliza el contacto indicado en la página.
