Muestra didáctica

Una guía que acompaña al alumnado

Un buen material aclara qué se va a aprender, permite practicar y ayuda a comprobar el progreso. El diseño parte de una tarea real, expresada con lenguaje cercano.

De un objetivo a una evidencia

  1. Objetivo observable. Crear una hoja de gastos con una suma correcta.
  2. Ejemplo resuelto. Mostrar una tabla pequeña y explicar cada decisión.
  3. Práctica con ayuda. Repetir el proceso cambiando los datos.
  4. Práctica autónoma. Resolver un caso similar con menos indicaciones.
  5. Evaluación y mejora. Revisar el resultado con criterios conocidos.

Una rúbrica sencilla

CriterioEvidencia de logro
OrganizaciónEncabezados claros y una fila por gasto
CálculoTotal correcto y comprobado
PresentaciónImportes legibles con el mismo formato
AutonomíaExplica cómo obtuvo el resultado
La pregunta clave: ¿qué podrá hacer el alumnado al terminar que todavía no podía hacer al empezar?
