Ofimática desde el primer día

Actividades cercanas para ganar autonomía digital.

Muestra didáctica

Aprender con tareas que tienen sentido

La ofimática resulta más cercana cuando se utiliza para resolver una necesidad conocida: redactar una carta, organizar un presupuesto o preparar una presentación.

Tres prácticas conectadas

  1. Un documento claro. Redacta una carta de presentación con título, párrafos y datos ficticios de contacto.
  2. Un presupuesto sencillo. Organiza seis gastos y calcula su total en una hoja de cálculo.
  3. Una presentación breve. Explica la propuesta en tres diapositivas: idea, presupuesto y conclusión.

Un método para empezar

Primero observamos un ejemplo; después lo repetimos con ayuda y, por último, resolvemos una situación parecida de forma autónoma. Cada práctica termina con una revisión breve.

Lista de comprobación: nombre de archivo comprensible, carpeta de destino localizada, contenido revisado y resultado guardado.

Conexión con mi experiencia

He impartido formación de ofimática básica con Dabo Consulting y actividades de Excel y ofimática en el Programa de Empleo y Formación del Ayuntamiento de Mairena del Aljarafe.
